Phase 0 - Python Foundations

This repository contains the projects I built during my Phase 0 preparation before starting the IB Diploma at UWC Maastricht. The goal of Phase 0 was to build a strong foundation in Python, automation engineering, and software project organization before beginning university-level computer science work.

Projects
Week 1 - Client Management System

A file and Excel automation project that creates client folders and generates spreadsheet trackers automatically.

Skills: File automation, folder management, Excel automation, GUI basics.

Week 2 - Automated Invoice System

A business automation project that generates professional PDF invoices and emails them automatically to clients.

Skills: PDF generation, email automation, file handling, business workflow automation.

Week 3 - Deadline Radar System

A desktop application for managing tasks and deadlines using a modular Tkinter architecture.

Skills: Object-oriented programming, Tkinter GUI development, modular project structure, local data storage.

Skills Covered
Python fundamentals
File and folder automation
CSV and Excel processing
PDF generation
Email automation
Object-oriented programming
Tkinter desktop applications
Modular Python project organization

These projects document my transition from Python beginner to junior automation engineer and form the foundation for the larger automation projects I plan to build at UWC Maastricht and beyond.
