# Week 3 - Deadline Radar System

A desktop application for tracking tasks and deadlines using a modular Tkinter-based architecture.

## Features

- Add and manage tasks
- Track deadlines
- Store task data locally
- Desktop graphical interface built with Tkinter

## Project Structure

- `app.py` - launches the GUI
- `database.py` - handles data storage
- `task.py` - defines the task model
- `task_manager.py` - manages task operations and application logic

## Skills Practiced

- Object-oriented programming
- Tkinter GUI development
- Modular application structure
- Data persistence
- Project organization across multiple Python modules

## Workflow

1. Create a task
2. Assign a deadline
3. Save the task locally
4. View and manage upcoming deadlines through the GUI

## Run

```bash
python app.py
```
