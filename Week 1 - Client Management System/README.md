# Week 1 - Client Management System

A desktop automation project that creates client folders and generates Excel tracking spreadsheets automatically for small business workflows.

## Features

- Create organized client folders automatically
- Generate Excel tracking spreadsheets automatically
- Write client information directly into spreadsheets
- Simple desktop interface for managing client records

## Skills Practiced

- Python file handling
- Folder and directory automation
- Excel automation with `openpyxl`
- Data writing and formatting
- Basic GUI development

## Workflow

1. Enter client information
2. Create a dedicated client folder
3. Generate an Excel tracking file
4. Save the file in the correct client folder

## Run

```bash
python client_management_system.py
```

This project was built during Week 1 of my Phase 0 Python Foundations program as an introduction to business automation and file management workflows.
