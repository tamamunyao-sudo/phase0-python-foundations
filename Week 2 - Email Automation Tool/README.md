# Week 2 - Automated Invoice System

A business automation project that generates professional PDF invoices and sends them automatically to client email addresses.

## Features

- Generate PDF invoices automatically
- Use a custom invoice template
- Insert client and project details dynamically
- Calculate invoice totals automatically
- Save invoices with organized filenames
- Send invoices automatically via email
- Attach generated PDFs to outgoing emails
- Create personalized email messages for each client

## Skills Practiced

- Python automation
- PDF generation
- Email automation
- File handling
- String formatting
- Business process automation
- Modular Python programming

## Workflow

1. Load client and invoice data
2. Generate a PDF invoice
3. Save the invoice locally
4. Create a personalized email message
5. Attach the PDF automatically
6. Send the invoice to the client

## Run

```bash
python invoice_system.py
```
